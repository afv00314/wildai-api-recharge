## 先分清：API 额度和 Claude Pro 会员不是一回事

这是最容易踩的坑，也是很多"充值平台"文章故意含糊的地方。

**Claude API（走 Console）**：按 token 计费，预付 credit，你拿到的是 API Key 和 base_url，接进 Cursor、Cline、自己的后端服务。这是开发者要的东西。

**Claude Pro 会员（claude.ai）**：固定月费的个人订阅，你拿到的是网页和客户端的更高使用额度、Projects、Claude Code 等能力，没有 API Key。

市面上说"Claude 充值"的平台，绝大多数卖的是第二种，即帮你把会员开通到你自己的账号上。如果你要的是往 Console 里充 API 额度，而平台只卖订阅，付了钱也用不上。下单前先确认清楚你买的是哪一种。

## Anthropic 官方充值，卡在哪几处

官方这条路本身不难，难的是前置条件。按 Anthropic 帮助中心的说明：

- API 和 Workbench 按**预付使用额度（prepaid credits）**计费，得先买再用；

- 余额见底后，API 调用和 Workbench 直接停摆，直到你再充；

规则清楚，问题是入口对国内用户不太友好：官方结算走国际信用卡通道，不支持支付宝和微信；注册和验证过程还涉及手机号、账单地址和地区判断。手里有稳定海外卡的人，直接在 Console 里点"购买 credit"就完事了，不需要看这篇文章的后面部分。

## 下单到开通，流程长什么样

按平台帮助中心和第三方教程的记录，整个流程大概是：

1. **注册账号**。手机号或邮箱验证码登录即可，国内号段可用。
2. **确认你要买的服务和时长**。Claude 走 Claude 的入口，ChatGPT 走 ChatGPT 的入口，别串单。
3. **提供账号凭证**。装浏览器插件，在你登录 Claude 的状态下抓取 Session / Cookie。这里要核对邮箱，填错账号是最常见的事故来源。
4. **通过环境检测**。IP 类型、DNS、浏览器指纹三项，数据中心 IP 通过率很低。
5. **微信或支付宝扫码付款**。国内银行卡也支持。
6. **等待开通**。官方教程说通常几分钟到两小时内生效，开通后回 claude.ai 刷新，确认账号已经变成 Pro。

如果你是给自己原有的账号订阅，第 3 步一定要在正确的域名和正确的插件下操作，别在群聊里随手点别人发来的链接。
